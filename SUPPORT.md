# Support

- **Questions and ideas:** open a discussion or an issue in the repository it concerns — [kit](https://github.com/delphi-modernizer/kit)
  for the methodology, [engine](https://github.com/delphi-modernizer/engine) for the scanner, CLI and gates,
  [studio](https://github.com/delphi-modernizer/studio) for the desktop app.
- **Bugs:** use the bug form, with the versions it asks for.
- **Security problems:** follow [SECURITY.md](SECURITY.md); never a public issue.
